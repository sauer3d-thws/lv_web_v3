💡 Zeilenweise Erläuterung im Skript:
  • 1. Array-Literale []: Geordnete Listen mit 0-basiertem Index.
  • 2. map(): Erzeugt ein neues Array durch Transformation jedes Elements.
  • 3. filter(): Extrahiert Untermenge aller Elemente, die eine Bedingung (true) erfüllen.
  • 4. reduce(): Summiert/berechnet ein gesamtes Array auf einen einzigen Endwert herunter.
