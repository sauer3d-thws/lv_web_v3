JavaScript Debugging Praxis-Test

Dieses Beispiel demonstriert Breakpoint-Debugging im Browser. Drücke F12, um die Entwicklertools zu öffnen, bevor du auf den Button klickst!

Ergebnis: -
Anleitung zum Debuggen:
  1. Entwicklertools mit F12 öffnen.
  2. Auf "Summe berechnen" klicken.
  3. Der Browser stoppt automatisch bei der Zeile debugger;.
  4. Im Sources / Scope Panel den Datentyp von a (String) und b (Number) prüfen.
