Datei-Export & Import (Blob & FileReader API) Praxis-Test

Obwohl JavaScript in einer isolierten Browser-Sandbox läuft, können mit der Blob API Dateien aus Formularwerten erzeugt und mit der FileReader API lokale GeoJSON-Dateien wieder eingelesen werden.

1. GeoJSON-Eigenschaften im Formular definieren & exportieren (Blob API)

Passe die Eigenschaften für den Geodaten-Punkt an. JavaScript baut daraus dynamisch eine strukturierte GeoJSON FeatureCollection und bietet diese zum Download an.

2. Lokale GeoJSON-Datei wieder einlesen & verarbeiten (FileReader API)

💡 Gezeigte Kernkonzepte im Code:
  • Dynamischer GeoJSON-Aufbau: Formulardaten auslesen und in ein strukturiertes JS-Objekt (FeatureCollection) überführen.
  • new Blob([jsonString], {type}): Verpackt den erzeugten JSON-String in eine Datei im Arbeitsspeicher.
  • URL.createObjectURL(blob): Erzeugt eine temporäre Download-URL für den Blob.
  • FileReader API: Liest vom Nutzer ausgewählte lokale Dateien per reader.readAsText() asynchron ein und stellt sie wieder im DOM dar.
